___
## Can a Configuration Be Reorganized Deliberately?

___
## Lesson 16

In the previous lesson,

we stopped treating a state

as an undivided experience.

We examined it as a configuration:

a thought,

a memory,

a bodily sensation,

a direction of attention,

an expectation,

an interpretation,

an impulse.

These elements can operate together

so closely

that the whole configuration appears simply as:

_I am anxious._

_I am angry._

_I need to do something._

But once the elements become distinguishable,

a different possibility appears.

If a configuration has elements,

and if those elements have relations,

then the configuration can be reorganized.

The question is:

**Can I deliberately alter its organization?**

If so,

**what exactly can be changed?**

Take a state that is actually present.

Something ordinary is best.

Irritation.

Anxiety.

Impatience.

Defensiveness.

A familiar worry.

Do not wait for a dramatic experience.

A small configuration is enough.

First,

observe it.

What is present?

What is being recalled?

Where is attention going?

What interpretation is becoming dominant?

What does the body feel like?

What does the state seem to expect?

What action does it prepare?

See the configuration.

Then stop.

Do not simply continue along the direction established by the state.

You are going to perform an operation.

Suppose anxiety is present.

Perhaps it is recalling previous situations.

Perhaps attention is concentrated on possible danger.

Perhaps the body is tense.

Perhaps the mind is repeatedly generating possible outcomes.

Perhaps uncertainty is being interpreted as threat.

Now ask:

**Does every one of these elements have to remain organized in exactly this way?**

Do not answer theoretically.

Test it.

Keep one element present.

Change another.

Observe the resulting configuration.

For example:

Keep the situation.

Change the interpretation.

Keep the memory.

Change the direction of attention.

Keep the bodily sensation.

Change the organization of thought around it.

Keep the original thought.

Do not add the usual continuation.

You are changing the relations through which the configuration is organized.

This is reconfiguration.

And if the resulting organization is different,

then the configuration has changed.

Imagine that you receive a message:

**“We need to talk.”**

The message appears.

That is one event.

Then Recall supplies a previous disagreement.

Attention moves toward the possibility of conflict.

The body becomes tense.

An interpretation appears:

_This is going to be bad._

Expectation follows:

_They are probably angry._

Then another thought:

_I always cause problems._

The elements have now formed a configuration.

And the configuration may feel like a single fact:

**Something is wrong.**

But look more carefully.

The message is one thing.

The memory is another.

The bodily sensation is another.

The interpretation is another.

The expectation is another.

The identity claim is another.

They have become one configuration,

but they are not one element.

Now deliberately reorganize it.

Keep the message.

Keep the memory.

Keep the bodily sensation.

But remove the assumption that the interpretation is already established fact.

Introduce another interpretation:

_I do not yet know what this conversation is about._

Now the organization has changed.

The message remains.

The memory remains.

The bodily sensation may remain.

But the relation between them has been altered.

The previous configuration has therefore been reorganized.

The important point is not whether the new configuration feels pleasant.

The important point is that a deliberate operation has changed its organization.

Now return to **Recall**.

In the previous lesson,

we examined Recall primarily as something through which previously formed material becomes available.

Now we can examine another property.

Recall does not only bring back material automatically.

It can also be used deliberately.

Suppose a current state is organized around irritation.

The memory that supports the irritation is one possibility,

but it is not necessarily the only one.

Perhaps you remember a previous situation

in which you remained calm.

Perhaps you remember a broader context

that changes the meaning of what is happening now.

Perhaps you remember another way of responding.

The important point is that **the current configuration does not exhaust the available organization.**

Other material exists.

Recall can deliberately make some of it available.

And once it becomes available,

attention can work with it.

Now notice

what happens when several possibilities become available.

You cannot give equal attention to everything simultaneously.

Attention differentiates.

One element becomes foreground.

Others recede.

This is **Differentiation**.

Until now,

we have mostly examined it as something that happens automatically.

Now introduce deliberate participation.

Suppose several interpretations are available.

One is threatening.

Another is uncertain.

Another is neutral.

Another is constructive.

You do not need to pretend that the threatening interpretation is impossible.

You simply distinguish its automatic prominence

from the question of whether it should determine the organization.

Look at the alternatives.

Compare them.

Ask which one is actually supported.

Then deliberately direct attention toward the one you judge most appropriate.

That is not suppression.

It is selection.

And selection is already a form of reconfiguration.

If the selected interpretation becomes the organizing interpretation,

the configuration has changed.

Do not assume that a configuration must remain active

simply because it arose automatically.

If anxiety is present,

you can deliberately reorganize the state

and establish another configuration.

If irritation is present,

you can establish a configuration organized around patience.

If fear is present,

you can establish another configuration

organized around clarity or appropriate action.

The operation is not:

“wait until the original state disappears.”

The operation is:

**change the organization.**

When one configuration is deliberately replaced by another,

the replacement is already an accomplished change.

A deliberate change in organization

has already occurred.

If another deliberate operation follows,

the resulting configuration can itself become

the basis for further change.

The possibility of further change

does not cancel the change that has already occurred.

You are not pressing a button and waiting to discover whether anything happened.

You are performing an operation

and examining the configuration that results.

Now make the experiment explicit.

Find a state that is currently present.

Observe its structure.

Then identify a different state

that you have actually experienced before.

Not an imaginary perfect version of yourself.

Something real.

Perhaps calm.

Perhaps patience.

Perhaps clarity.

Perhaps confidence.

Perhaps firmness.

Perhaps simple attentiveness.

Recall the situation

in which that configuration was present.

What thoughts belonged to it?

What was attention doing?

How did the body feel?

What interpretation was active?

What expectation was present?

What action followed naturally from it?

You are not merely remembering an emotion.

You are recalling a configuration.

Now deliberately make its elements available.

Bring them into the present.

Direct attention toward them.

Allow the body to participate.

Establish the organization associated with that configuration.

Then observe it.

You have moved from observing one configuration

to deliberately establishing another.

We need to be precise here.

If you are anxious,

and you tell yourself:

_Everything is wonderful._

you may simply be adding another thought.

That is not what we are testing.

If you are angry,

and you force yourself to say:

_I am peaceful._

you may simply be imposing a statement

without reorganizing the configuration.

That is not what we are testing either.

The operation is structural.

We are asking:

**What configuration is currently active?**

**What configuration do I want to establish?**

**Which elements belong to that configuration?**

**Can Recall make those elements available?**

**Can Differentiation direct attention toward them?**

**What organization results?**

This is why the practice is not fundamentally about positive or negative emotion.

It is about **deliberate organization**.

You are learning to work with configurations.

The body is part of the configuration.

That does not mean the body is an isolated mechanism that can be commanded independently.

It means that bodily organization can participate in deliberate reconfiguration.

Return to the earlier example of anxiety.

The body may be tense.

The breathing may be shallow.

The posture may be contracted.

You can deliberately change these elements.

Slow the breathing.

Release unnecessary muscular tension.

Change the posture.

Widen the field of physical attention.

Then observe the resulting configuration.

Do not tell yourself:

_This must make me calm._

Instead ask:

**What configuration results when the bodily organization changes?**

The important point is that the bodily change itself is already an operation.

If the organization changes,

then the configuration has changed.

PRACTICE.

A simple example makes the operation clearer. Suppose a state of irritation or anxiety is already active, but you have previously experienced a genuine state of quiet attention that you can still recognize. You do not need to tell yourself that you are calm. Instead, deliberately recall that previously formed state and bring its organization into the present: direct attention in the way associated with it, and let the breath become slower and less contracted. The breathing is one accessible element through which you participate in the reorganization, while Buddhi deliberately selects and holds the direction of the calmer configuration. Try bringing the state of calm that you have recalled down into the body through the breath. You are not fighting the anger or irritation; you are simply replacing one configuration with another. You are not merely describing calm; you are establishing a different organization of experience. You are reconfiguring the very elements that make up the state. These may include the breath, the position of the body—for example, relaxation in this case, or shoulders held open to convey a sense of confidence. They may also include the thought itself and the emotion that you have recalled and are now deliberately re-establishing as elements of a new experience. With sustained practice, this can become like working with a construction set, where you select new states and ways of experiencing reality with engineering precision.

So, let us look at what makes the reconfiguration possible.

When a state begins to gather, first observe it.

What is present?

What is its organization?

What is it recalling?

Where is attention going?

What interpretation is dominant?

What does the body contribute?

What action is being prepared?

Then identify an alternative configuration.

What other organization is actually available?

Recall it.

Bring its elements into present availability.

Direct attention toward them.

Allow thought, bodily organization, and action to support the selected direction.

Then establish the new configuration.

Finally, observe what is present now.

What changed?

The important point is that you are not performing a technique and then waiting to discover whether it “worked.”

You are observing the configuration that you have deliberately established.

A deliberate replacement is an actual change.

If one configuration is replaced by another, the organization has changed.

The fact that the new configuration may later change again does not cancel the first change.

You may establish one configuration, and later establish another.

The sequence can continue:

**A → B → C.**

This is not a failure of the first replacement.

It is simply the possibility of further reorganization.

The distinction is between **change** and **permanence**.

We are establishing that deliberate reconfiguration is possible.

But permanence requires a particular discipline.

This is where **Buddhi** changes status.

Earlier, we used Buddhi primarily as discrimination.

It could distinguish:

thought from fact,

state from identity,

interpretation from certainty.

Now discrimination becomes operational.

Buddhi can examine a configuration and ask:

**What is this configuration composed of?**

**What relations organize it?**

**What alternatives are available?**

**Which configuration should be established?**

The answer is not necessarily the calmest or most pleasant state.

If anger is pushing toward an action you know to be destructive,

Buddhi can recognize that direction.

If anxiety is producing endless rehearsal without useful action,

Buddhi can recognize that as well.

If firmness is actually required,

Buddhi does not have to choose calm merely because calm feels pleasant.

Buddhi is an instrument of awareness.

It makes the configuration available to conscious examination,

reveals its elements and relations,

and makes deliberate selection possible.

The goal is not:

**always become calm.**

The goal is:

**deliberately select and establish the configuration appropriate to the situation.**

Sometimes that will be calm.

Sometimes patience.

Sometimes firmness.

Sometimes withdrawal.

Sometimes action.

Sometimes refusal.

Sometimes continued investigation.

The meta-level does not dictate one emotional state.

It gives you the capacity to work with states as configurations.

The same principle can now be stated more generally.

We began with an automatic state.

We observed it.

We differentiated its components.

We identified another configuration.

We made its elements available through Recall.

We directed attention toward them.

We allowed the body and attention to participate.

Then we deliberately established a different organization.

The sequence is:

**appearance → observation → differentiation → selection → reconfiguration → observation of the new configuration.**

With experience, it may become possible to move from one configuration to another

without going through this entire, lengthy, and demanding procedure.

To replace one configuration with another,

one state with another.

This is not detachment from experience.

It is the ability to experience it consciously.

And this operation is not limited to emotional states.

A thought can be examined.

A chain of thoughts can be examined.

A belief can be examined.

A behavioral pattern can be examined.

A worldview can be examined.

A philosophical framework can be examined.

A scientific model can be examined.

A religious interpretation can be examined.

In each case, the same questions become possible:

**What is this construction doing?**

**What elements compose it?**

**What relations hold it together?**

**What does it make visible?**

**What does it make invisible?**

**What alternatives are available?**

**What happens if the organization is changed?**

The scale has changed.

The logic has not.

This is where the deeper purpose of the practice becomes visible.

The goal is not to become permanently outside every state.

It is to develop the capacity to move between levels of organization:

to experience a state,

to observe it,

to examine it,

to modify it,

to enter another configuration,

to compare the two,

and to return to the observing position when necessary.

The same applies to conceptual systems.

You can enter a philosophical framework.

Allow its distinctions to organize the problem.

Think through it completely.

Then step back.

Examine the framework itself.

Compare it with another.

Use whichever construction provides greater explanatory power for the problem at hand.

Then move again.

The framework becomes an instrument.

It does not become a prison.

This is the beginning of the **meta-systemic position**.

The first state that appears

is not necessarily the state you must continue.

The first interpretation that appears

is not necessarily the interpretation you must keep.

The first behavioral impulse

is not necessarily the action you must take.

The first conceptual model

is not necessarily the model you must use.

The first worldview

is not necessarily the worldview through which every problem must be interpreted.

What appears first is simply what has appeared first.

It may be useful.

It may be correct.

It may be necessary.

But its position in the sequence does not automatically give it authority.

That is a fundamental meta-systemic distinction:

**Emergence does not establish supremacy.**

Something can arise automatically

without determining what you deliberately establish next.

Now perform the experiment once more.

Wait for a mild state.

Observe it.

Do not fight it.

Do not obey it.

Map it.

Ask:

**What is this configuration made of?**

**What is maintaining it?**

**What alternative configuration is available to me?**

Choose one.

Recall it.

Make its elements available.

Direct attention toward them.

Allow the body to participate.

Establish the new configuration.

Then observe.

Do not ask:

**Did I succeed?**

Ask:

**What configuration is present now?**

What changed?

Did attention change?

Did the body change?

Did the interpretation change?

Did the impulse change?

Did the organization change?

Every answer tells you something about the operation you have performed.

A state can arise without being chosen.

Observation makes its configuration distinguishable.

Distinguishability makes its elements and relations available for operation.

Recall can make a previously formed organization available.

Differentiation can redirect attention.

Buddhi can distinguish available configurations and select one.

Attention, body, interpretation, memory, and action can all participate in reorganization.

If one configuration is deliberately replaced by another, the organization has changed.

The operation has already occurred.

This gives observation its full practical meaning.

Observation is not the end of the process.

It makes what is happening visible enough to work with.

A state becomes a configuration.

A configuration becomes an object.

An object becomes available for examination.

Examination makes alternatives visible.

Alternatives make selection possible.

Selection makes deliberate reorganization possible.

And deliberate reorganization changes the configuration that is present.

It is the ability to work with manifestation

without being confined by the boundaries of established beliefs.

It is the ability to think

beyond established paradigms.

And it is precisely this experience

that reveals Logical Gnosis.
